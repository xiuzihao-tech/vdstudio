# 后台与技能（11/9）

视频站的后台做成了 dazheip 后台的样子：明黄侧栏、「管理权限」、「管理菜单」，右边眉标 + 标题 + 刷新，描边数据块、黑表头表格。
新功能直接插进 dazheip 原有菜单里（不另起分组）；dazheip 原有的几项（知识与情报、策略中心、会员管理…）在视频站没有，点了去主站后台。

**所有功能的提示词、规则、价格、奖励都做成了「技能包」，能单独维护**：仓库 `skills/` 里一个功能一个文件夹，后台「技能中心」能改、存版本、试运行、回滚。

## 怎么进后台

**后台不在前台显示**：前台菜单里没有任何后台入口，学员看不到。后台的地址是 `域名/admin`（比如 `https://video.dazheip.com/admin`），打开是后台登录页，**只有后台账号能登进去**；普通账号输对密码也进不去（「这个账号没有后台权限」），前台的登录状态不受影响。

| 谁 | 怎么开通 | 能看什么 |
| --- | --- | --- |
| 超级管理员 | 服务器 `.env` 的 `ADMIN_EMAILS`（逗号分隔）；直接在 `/admin` 登录，还没注册过的第一次登录就用填的密码建好账号 | 全部，还能加别的后台账号 |
| 运营 / 财务 / 技术 / 客服 | 超级管理员在后台「后台账号」里加邮箱、选角色；对方直接在 `/admin` 登录（第一次登录设密码） | 按角色，见下表 |
| 离线 / 在线演示版 | 右下角「演示版 · 后台登录」，演示账号 `admin@demo.local` / `dazhe2026`（登录页有「填入」） | 超级管理员 |

演示账号来自 `DEMO_ADMIN_LOGIN`，只给演示版用，正式部署设了会拒绝启动。后台左下角：「返回前台」（管理员视角，没开放的模块也能看到）、「按学员看前台」（和学员看到的一样，右下角小条能退出或回后台）、「退出登录」。

| 运营 | 数据总览、技能中心、邀请赠送、出片任务、视频站用户、模块开关、兑换码与邀请码、用户反馈 |

### 两种改法

1. **后台改**（运营日常）：技能中心 → 打开技能 → 改提示词 / 参数 → 写一句「改了什么」→ 保存。存成新版本、马上生效，前台刷新就用新的。
   - 「试运行」：用例子或自己写的输入跑一遍，能选「跟线上一样 / 只用规则 / 强制大模型」，能用**没保存的修改**跑；看输出、拼好的提示词、没换上的变量、模型原始回复。试运行不记调用、不扣任何人的积分。
   - 「版本」：每一版谁改的、什么时候、改了什么；能切到任何一版、「恢复默认」（回到仓库里的版本），也能把某一版的内容放回编辑区再改。
   - 「调用记录」：最近的调用走的大模型还是规则、成功没有、耗时、错误。
   - 停用 AI 技能 = 不调大模型，全按规则兜底。
2. **改仓库文件**（开发 / 大改）：改 `skills/<id>/` → `npm run skills` → 提交。后台「导出 JSON」能把线上调好的版本下载下来，`node scripts/skill-import.mjs 下载的文件.json` 写回仓库（`--dry` 先看会改什么），提交后它就是新的默认值。

后台存的版本优先于仓库默认；仓库后来加的新字段 / 新提示词段，老版本也能自动用上（合并时补齐）。保存前服务端按 `src/server/skills/validate.ts` 检查格式（比如话题最少数不能大于最多数、价格要是正整数、至少留一类成片开放），不对就不让存，并说清楚哪里不对。

### AI 技能怎么跑

接了文案大模型、技能启用、参数里 `useLlm` 是 true → 按提示词让模型出，代码检查格式（比如推荐的类型必须在可选列表里、分镜不能丢台词、标题文案不能有禁词），不合格或出错就按规则兜底。没接大模型时全部走规则，出来的和以前一样。每次调用都记一条（技能列表能看近 7 天调用、走模型几次、失败几次）。

提示词里的 `{{名字}}` 是运行时换进去的内容（用户的文案、素材、可选类型、目标时长…），不要删；试运行会提示哪些没换上。

- **密钥加密存**（AES-256-GCM），只显示打码后的样子（`sk-••••1234`，PEM 只说填了几行）；不改就留空，「清除后台填的」回到环境变量。加密用服务器的 `SECRETS_KEY`，**上线必须设，设了别改**（改了以前填的密钥解不开，要重新填）。操作日志只记改了哪些字段，不记内容。

## 积分系统

1 积分 ≈ 1 秒成片。流水按类型记（`src/shared/points.ts`），后台能按类型统计、按人搜：

| 类型 | 说明 | 类型 | 说明 |
| --- | --- | --- | --- |
| 充值 | 买的 | 注册赠送 | 注册成功送（每个账号一次） |
| 消耗 | 出片扣的 | 邀请好友 | 邀请人得的 |
| 失败退回 | 生成失败自动退 | 受邀注册 | 好友得的 |
| 兑换码 | 线下收款发的码 | 好友充值返点 | 邀请人从好友充值里得的 |
| 管理员调整 | 后台手动加减（要写原因） | 首充奖励 | 第一次充值多送的 |
| 退款扣回 | 订单退款扣回 | 分享奖励 | 每天第一次分享 |
| 奖励收回 | 刷号收回、退款带回 | 其他 | 老数据分不出来的 |

「充值发放」和「赠送发放」分开统计，对账时真金白银和送的不会混在一起。

积分规则（技能 `points`）：积分叫什么、1 积分几秒、样片 = 成片 × 比例（默认 0.4）、样片最低、每条最低、新访客试用积分（空 = 跟服务器 `INITIAL_POINTS`）、注册赠送、余额不足提醒线、诊断解锁价、订单有效期、充值套餐（在「充值订单」页改）。成片价格在「积分系统 → 成片类型与价格」改，停用的类型前台不显示。

## 邀请赠送（积分赠送）

**流程**：前台「余额与充值」里的「邀请有礼」（侧栏余额下面有入口）→ 复制链接 / 生成海报（黄底 + 二维码，能直接存图）→ 好友打开 `?ref=邀请码` 的链接，顶部提示「XX 邀请你，注册多送 N 点」→ 好友注册：**双方得点** → 好友充值：**邀请人按比例返点**，好友首充还有奖励。

| 规则（技能 `referral`） | 默认（占位，等定） |
| --- | --- |
| 邀请人得 / 好友得 | 100 / 100 点 |
| 什么时候发 | 好友注册成功就发（可改成「好友第一次出片后」「好友第一次充值后」，越往后越防刷） |
| 每人每天 / 每月最多奖励 | 10 / 50 个（超过的好友照样拿自己那份） |
| 同一网络 24 小时最多 | 3 个（同一 IP 用同一个邀请码注册超过就不发） |
| 邀请人返点 | 好友每次充值到账积分的 10%，注册后 365 天内，每个好友最多返 5000 点 |
| 首充奖励 | 0（固定值 + 比例都能设；任何人第一次充值都送） |
| 每天第一次分享奖励 | 0 |
| 分享标题、文案、规则说明 | 规则说明里 `{inviter}` `{invitee}` `{rate}` `{days}` `{dailyCap}` `{monthlyCap}` 自动换成上面的数 |

**防刷**：自己邀请自己不算；每笔奖励有唯一编号，重复触发不会多发；订单退款时这笔订单带出的首充、返点自动收回；后台「邀请记录」能按状态筛（已奖励 / 等好友出片或充值 / 超过上限 / 同网络重复 / 已收回），发现刷号点「收回」，邀请人和好友这条邀请得的点都扣回（扣到 0 为止）。邀请制（`INVITE_REQUIRED=1`）下，好友的分享链接也能当邀请码用。

模块开关里「邀请有礼」提到一期（默认打开）；关掉只是前台不显示入口。规则里的「开启邀请赠送」关掉 = 链接照常能打开，但不再发奖励。

## 部署要设的

```
ADMIN_EMAILS=你的邮箱
SECRETS_KEY=$(openssl rand -hex 32)      # 后台填的密钥用它加密；没设会用 FILE_SIGN_SECRET，启动时提醒
DAZHEIP_ADMIN_URL=https://www.dazheip.com/admin
```

数据库自动升级（第 10 次迁移）：老的积分流水按原因补上类型和账号；以前后台存过的「充值套餐」第一次启动时搬进技能「积分规则」（存成一个版本）。
