# 上线路线图（从本地试用到正式上线）

> 这份文件是开发的总指引：每一步做什么、做完怎么验证、需要你提供什么。已完成的功能清单见 `PLAN.md`。

## 当前状态

- 功能：选题文案、简易生成、制作台（基础版）、素材库、排期与 AI 预选题、账号、邀请制、管理后台、额度与开关、埋点与反馈、整条视频合成。
- AI：文案走 **OpenLux**（OpenAI 兼容，`https://api.openlux.ai/v1`），视频走 **土豆 API**（new-api 网关，异步视频端点 `/v1/video/generations`）。
- 运行：本机 `启动.command` / `npm run local`；部署包（Docker + Caddy）已备好未上线。

## 阶段 A · 接通真实 AI（本轮）

| 步骤 | 内容 | 验证 |
|---|---|---|
| A1 | 土豆视频适配器：Seedance 2.5 / 2.0 / 2.0 Fast / 万相 3.0 映射到土豆模型名；建任务、轮询、取视频地址；状态与字段做兼容解析 | 假服务器单测；本机生成一条 5 秒样片 |
| A2 | 后台「AI 服务」：显示接入状态；一键拉取两个站的可用模型；切换默认文案模型和各视频档位对应的模型（存数据库，不用改 `.env`、不用重启）；一键测试连通 | 后台点「测试」返回成功 |
| A3 | 本机 `.env` 写入两把密钥（只在你电脑上，不进 git）；`检测AI接口.command` 实测；选定默认模型 | 文案页生成一条真实文案 |

## 阶段 B · 上线预留（本轮先把结构留好）

| 模块 | 现在 | 上线时换成 | 预留方式 |
|---|---|---|---|
| 文件存储 | 本机 `data/files` | 阿里云 OSS / 腾讯云 COS / S3 + CDN | `Storage` 接口，`STORAGE=local｜s3` |
| 数据库 | SQLite 单文件 | Postgres（几十人以上） | 数据访问集中在 `repo.ts`、`ops.ts` |
| 任务执行 | 进程内 | 队列（BullMQ / 云函数） | `JobRunner` 一处收口 |
| 登录 | 邮箱 + 密码 | + 手机验证码 / 微信登录 | `auth.ts` 加登录方式 |
| 计费 | 点数（后台手动加） | 充值（微信 / 支付宝） | 点数流水 `ledger` 表已在 |
| 前端地址 | 同源 `/api` | 前后端可分开部署 | `API_BASE` 构建变量 |

## 阶段 C · 正式上线（需要你提供）

1. 云服务器（2 核 4G 起）+ 域名；**国内服务器需要 ICP 备案**（约 1–3 周，先办）。
2. 对象存储桶 + CDN 域名。
3. 生成式 AI 内容合规：页面与成片标注「AI 生成」（已有）；面向公众提供服务需按《生成式人工智能服务管理暂行办法》做算法 / 大模型备案或使用已备案模型，并建立内容审核。
4. 支付商户号（如要收费）。
5. 按 `docs/DEPLOY.md` 部署，`docs/VALIDATION.md` 做小范围验证，再逐步开放。

## 安全约定

- 密钥只放 `.env`（已在 `.gitignore`），**绝不提交到 GitHub**；仓库目前是公开的。
- 密钥在聊天里出现过，正式上线前建议在两个站各重新生成一把，旧的作废。
