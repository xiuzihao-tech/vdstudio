# 充值与支付 · Seedance 2.5 样片模式（2026-11-04 加）

## 充值
- 入口：左下角余额（「1点=1秒 · 充值 ›」）→「余额与充值」页：套餐、微信 / 支付宝、兑换码、订单、点数流水。
- 出片时余额不够：在当前页直接弹充值，付完接着生成，不用跳走。
- 默认套餐（后台「充值订单」里随时改，马上生效）：

| 套餐 | 价格 | 到账 | 其中赠送 |
|---|---|---|---|
| 体验包 | ¥19.9 | 200 点 | 0 |
| 常用包 | ¥99 | 1,100 点 | 110 |
| 进阶包（推荐） | ¥299 | 3,500 点 | 510 |
| 专业包（最划算） | ¥999 | 12,500 点 | 2,510 |

  基准 ¥1 = 10 点，1 点≈1 秒成片。**价格是占位**，要按方舟 Seedance 实际计费和毛利再定。
- 大哲诊断账号 ¥899 也走同一套下单付款，付完自动解锁（价格后台可改）。

## 支付渠道
- 微信支付：Native 扫码，APIv3（商户私钥签名，回调用微信支付公钥验签、APIv3 密钥解密）。
- 支付宝：当面付扫码 alipay.trade.precreate，RSA2。
- 到账：支付平台回调 `/api/pay/notify/wechat|alipay`；回调没到时，页面轮询订单会主动查一次单。同一笔只入账一次，金额对不上不入账。订单 15 分钟不付自动关闭。
- 一个渠道都没配 = 只有「模拟支付」（演示用）。配了真实渠道模拟支付自动关掉；生产环境开 `PAY_MOCK=1` 会拒绝启动。
- 退款：后台「标记退款」只扣回点数，钱要在商户后台原路退。
- 上线要准备：微信支付商户号 + 绑定的 AppID + 商户证书 / 私钥 + APIv3 密钥 + 微信支付公钥；支付宝开放平台应用（开通当面付）+ 应用私钥 + 支付宝公钥；`PUBLIC_BASE_URL` 是 https 公网域名。配置项见 `.env.example`。
- 还没做：手机里在微信内付款（JSAPI，要 openid）、H5 支付、发票。现在手机上是扫码付。

## Seedance 2.5 样片模式（一键生成视频第 3、4 步）
- 第 3 步两个按钮：**先出样片**（480p，成片价四成，例：真人口播 60 点 → 样片 25 点）/ 直接出成片。
- 样片好了在第 4 步看，满意点「满意，出 1080p 成片」：方舟用样片任务续出（`content: [{ type: 'draft_task', draft_task: { id } }]`），画面、时长、比例都沿用，不重新抽卡；样片 7 天内有效，过期或改过分镜就照常重新生成。
- 只有成片能下载、能进发布队列。不满意「回分镜改」再出一条样片。
- 走真实生成任务：失败自动退点，关掉页面也会接着生成，回来在「上次未完成」里看。
- 走土豆网关时，样片用网关里最便宜的模型出预览（网关不支持续出），成片重新生成。
