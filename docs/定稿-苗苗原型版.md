# 定稿：视频 IP · 苗苗原型版（2026-11-04）

以后都在这一版上继续开发。代码基线：vdstudio 的 `miaomiao-final` 分支（定稿快照，不再改动），日常开发继续在 `main` 上。
依据：文档《视频IP改版修改意见》（2026-11-04 和苗苗开会）+ 之后三次调整。

## 菜单
- 不再有「视频 IP」分组。五个入口和 dazheip 原有菜单同一个样式，插在「制作封面图文」后面：
  大哲诊断账号（未解锁带锁）→ 一键生成视频 🔥 → 管理我的素材 → 安排发布计划（本周条数）→ 查看作品数据。
- dazheip 原有入口不动（开始创作文案、查找选题灵感、制作封面图文、常用创作工具、大哲实战课堂、家居IP资讯、我的资产）。
- 旧页面（今天、AI 运营、知识库与形象、口播数字人、生成视频）代码保留，菜单里不出现。

## 两个入口，回到同一处
付费诊断 → 选题进「安排发布计划」（待确认）；直接出片 →「加入发布队列」回到「安排发布计划」（已排期）。

## 大哲诊断账号（可选）
- ¥899 一次解锁、永久可用、不按次扣点；解锁前可看盛哥示例报告。演示版不真收款。
- 四段深聊（身份与品牌 / 个性抓取 / 专业与优势 / 愿望与栏目），不限题数，随时「结束并生成诊断」，可语音，有「一键演示 · 盛哥（木里木外）」。
- 结果：个性 / 专业 / 品牌三类标签 + 四档栏目（说明、示例选题、频率、来源标签），都能改。
- 第二轮：每档能拍几套 → 一周 3 条排约 15 条选题 →「保存，进入发布计划」。

## 一键生成视频
- 首页：拖素材区 +「还没做账号诊断？」+ 上次未完成 +「成品长这样」样片（按类分，创意模板不定期上新，TVC 可定制）。
- ① 文案和素材：**左文案、右素材，成片类型在下面通栏（下拉，默认交给 AI）**。没文案 → 跳 dazheip「开始创作文案」；有素材还能「让 AI 看素材写」。
- ② AI 建议：AI 说明 + 标签；数字人口播 / 不露脸两栏，换数字人；推荐卡带组成示意图；时长、比例、字体、音乐、声音；换一类（带点数）。
- ③ 确认分镜：故事梗概，每镜可加自己的照片 / 视频，生成前扣点确认。
- ④ 成片与发布：预览、下载、封面 A/B/C +「去封面工具精修」（dazheip /covers）、标题 ≤30 字、发布文案、话题选 3–5 个；没有「保存草稿」；「加入发布队列」回发布计划。
- 价格：空间漫游 80、空间讲解 70、真人口播 60、改造前后 90、案例故事 100、产品种草 65、工地记录 55、Vlog 70（点，1 点≈1 秒）。

## 管理我的素材
素材 / 数字人与声音（自己的分身、照片形象、声音 + 4 个系统数字人）/ 品牌资料（原知识库）。「数字人与品牌」不再单独一页。
