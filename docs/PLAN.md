# 开发计划

## 里程碑

| 阶段 | 内容 | 状态 |
|---|---|---|
| M0 工程底座 | 目录、构建、API 框架、SQLite 与迁移、设计变量、导航、弹层与提示 | ✅ 完成 |
| M1 选题文案 | IP 定位；三个入口（案例策划 / 对标复刻 / 素材创作）；选题库五项组合筛选；深挖角度；收藏；文案编辑（类型 / 时长 / 语气、标题与钩子备选、逐段编辑）；实时检查（时长、违禁词、活人感）；改写；草稿；封面；工具（声音克隆、音频 / 视频提文案、违禁词、活人感、爆款拆解）；实战课堂；我的资产 | ✅ 完成 |
| M2 简易生成 | 文案 / 提示词 / 素材；模型、时长、比例、清晰度、样片模式、声音、语速、音乐、字幕、环境声、封面、风格；冲突检查与一键修复；生成任务（扣点、进度轮询、失败退点）；样片转成片 | ✅ 完成 |
| M3 素材库 | 真实文件上传（图片、视频、音频，200MB 上限）；多选；送去简易生成 / 制作台 / 写文案；删除 | ✅ 完成 |
| M4 排期 | 多账号；发布日、时间、样片确认、栏目配比、月预算；AI 预选题审核（通过、换一个、从选题库挑、全部通过、重新预选）；备选池；选题库 ↔ 排期双向联动（选题卡显示排期状态，排期可跳到选题库“放到这天”）；选题挪日期时原日期自动补位 | ✅ 完成 |
| M5 制作台 | 基础版：逐镜台词、时长、景别、运镜、生成方式、首帧素材，增删排序，全片设置，整条生成 | 🟡 基础版 |
| M5+ 制作台完整版 | 移植原型控台：机位摇杆、角度、构图、多版本对比、种子锁定、时间线、逐镜重拍 | ⏳ 下一轮 |
| M6 真实接入 | 账号登录与团队；对象存储（OSS / COS）与转码；文案大模型；大哲选题库接口；Seedance（火山方舟）视频生成与回调；TTS 与声音克隆；违禁词库；计费与充值；发布到抖音 / 小红书 / 视频号 | ⏳ 下一轮 |
| M7 上线准备 | Postgres 迁移、任务队列（BullMQ / 云函数）、监控告警、限流、审计日志、内容安全审核 | ⏳ |

## M6 接入清单（需要你方提供）

- 大哲选题库：接口文档与密钥（热门选题、案例策划、对标拆解）
- 文案模型：选型（豆包 / DeepSeek / Claude 等）与密钥
- 视频：火山方舟 Seedance 账号与密钥，确认价格与并发
- 声音：TTS 与克隆服务选型，授权协议文本
- 存储：对象存储桶与 CDN 域名
- 计费：点数与人民币换算、充值方式、失败退点规则
- 发布：各平台开放接口资质

## 已知取舍

- 服务端没有引入 Web 框架，路由处理函数是纯函数，迁到 Next.js Route Handlers / Hono 时可直接搬。
- Mock 生成任务在进程内跑，服务重启会把未完成任务标为失败并退点；接入真实服务后改为外部任务 ID + 回调。
- 排期“今天之前”的格子一律视为已发，正式版要以发布回执为准。
