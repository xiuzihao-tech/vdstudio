# 大哲诊断 · 标签与栏目

**在哪用**：聊天页点「结束并生成诊断」。结果页的标签、栏目都能被用户再改。

**跑法**：接了大模型就按 `prompt.md` 的 `report` 生成，代码会校验格式（栏目数、片型必须是成片类型里有的）；不合格或没接大模型，就按规则出：
- 回答里出现 `sampleKeyword`（默认「木里木外」）时直接给 `sample`（盛哥的示例报告）——演示用，正式上线可以把关键词清空。
- 否则从回答里找 `personal` 词表里的词当个性标签，按回答拼专业 / 品牌标签和四档栏目。

**config.json**
| 字段 | 说明 |
|---|---|
| `columns` | 出几档栏目（默认 4） |
| `sample` | 示例报告（解锁页「先看盛哥的诊断结果」也用它），苗苗润色后改这里 |
| `sampleKeyword` | 回答里出现这个词就直接给示例报告；清空就不触发 |
| `personal` | 规则兜底时识别个性标签的词表 |

**提示词变量**：`{{answers}}` 回答列表、`{{columns}}` 栏目数、`{{types}}` 可选片型 id。
