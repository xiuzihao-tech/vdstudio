# 成片参数

- **durations**：时长选项。第一项「AI 推荐」按成片类型的推荐时长；其余写成「30 秒」这样（数字 + 秒），扣点按秒数折算。
- **ratios**：画面比例（9:16 竖屏、3:4 竖屏、1:1 方形、16:9 横屏）。土豆网关只认 9:16、16:9、1:1，3:4 会按 9:16 出。
- **fonts**：字幕字体。`note` 是授权说明，显示在下拉下面——**商用前必须确认授权**；`enabled` 关掉就不出现。
- **bgm**：背景音乐。`n` 是用户看到的名字，`mood` 是适合什么片，`use` 是合成时用曲库里的哪首（温暖钢琴 / 城市律动 / 弦乐氛围 / 轻电子 / 不要）；新加音乐要先把曲子放进服务端曲库再填 `use`。
