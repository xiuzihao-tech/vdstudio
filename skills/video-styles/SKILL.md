# 视频风格

每个风格决定三件事：**文案怎么写**（交给写文案的大模型）、**画面怎么拍**（交给视频模型，Seedance / 网关的每镜提示词里都会带上）、**节奏和包装**（每镜几秒、默认音乐、字幕样式）。

| 字段 | 说明 |
| --- | --- |
| `id` | 英文编号，别改（老数据靠它找风格） |
| `n` | 风格名，用户看到的 |
| `like` | 参考谁（大家熟悉的账号或片种）：只学写法和节奏，不用对方的素材和名字 |
| `d` | 一句话：好在哪 |
| `best` | 最适合的视频类型（旧版生成页用：real 实拍、talk 口播、tour 漫游、house 改造、story 故事、product 产品、site 工地、vlog） |
| `copy` | 文案写法（给大模型） |
| `visual` | 画面拍法（给视频模型） |
| `pace` | 每镜大约几秒 |
| `bgm` | 默认音乐（曲库：温暖钢琴 / 城市律动 / 弦乐氛围 / 轻电子 / 不要） |
| `subs` | 字幕样式：`doc` 纪录片小字、`key` 关键词大字黄底、`plain` 普通 |
| `hot` | 招牌风格，排最前 |
| `draft` | 还没和大哲 IP 研究院对过样片 |
| `enabled` | 关掉就不出现在选择里 |

**typeDefault**：一键生成视频的 8 类成片选「AI 推荐」时默认用哪个风格（填风格的 `id`）。

加新风格：在列表里「新增一项」，填好 `id`（英文、不重复）和上面各项；停用比删除好（老视频还能找到风格名）。
