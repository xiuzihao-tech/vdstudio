# 数字人形象与声音

**avatars**：前两个（`mine: true`）是用户自己的真人分身 / 照片形象（在「管理我的素材」里建）；其余是系统形象。
`skin` 肤色、`hair` 发色、`hairStyle`（crop / short / bob / long）、`top` 衣服颜色、`bg` / `bg2` 背景渐变、`glasses` 戴不戴眼镜——页面上用这些画出示意头像。接真实数字人服务后，每个形象再加对应的服务端形象 id。

**voices**：声音下拉的选项（第一项用本人声音，没录就退回 AI 配音）。
