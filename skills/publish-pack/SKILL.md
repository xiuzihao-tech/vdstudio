# 出片 · 发布包装

**在哪用**：成片 / 样片出来后的「发布清单」：标题、发布文案、话题，以及封面上的大字（取标题）。

**跑法**：接了大模型按 `prompt.md` 的 `pack` 写；否则按规则：标题取第一句（不超过 `titleMax` 字），正文串前几句再接 `cta`，话题按 `groups` 模板生成（`{city}` 城市、`{type}` 片型名），默认勾上 `pick` 序号的几个。

**config.json**
| 字段 | 说明 |
|---|---|
| `city` | 默认城市（用户资料里有城市时用用户的） |
| `titleMax` | 标题字数上限 |
| `cta` | 正文最后一句的引导 |
| `groups` | 话题分组和候选 |
| `pick` | 默认勾上第几个（按全部候选从 0 数） |
| `tagMin` / `tagMax` | 话题最少 / 最多选几个（多了会被判堆砌） |
| `banned` | 广告法敏感词：标题、文案里出现会提醒用户改（dazheip 后台的「合规规则」可以同步到这里） |
