# 视频 · 土豆网关

**用在**：同「视频 · 火山方舟」。两个都配了时，按「视频用哪家」的选择（默认优先网关）。

**接口约定**：`POST {接口地址}{创建路径}` 提交，返回任务 id；轮询查询结果。样片用网关里最便宜的模型出预览，**不支持**方舟的样片续出，成片会重新生成。

**档位模型**：把我们的档位（s25 / s20 / draft…）映射成网关里的模型名。

**测试连接**：拉一下 `/models` 列表。
