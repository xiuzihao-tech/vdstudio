# 大哲诊断 · 排选题

**在哪用**：诊断结果页「栏目就这样，接着排选题」→ 回答每档数量 → 出选题 →「保存，进入发布计划」。

**跑法**：接了大模型按 `prompt.md` 的 `topics` 出（代码校验：条数、栏目名必须是诊断里的、片型合法）；否则按 `templates` 模板出。

**config.json**
| 字段 | 说明 |
|---|---|
| `total` | 一共排几条（默认 15 = 一周 3 条 × 5 周） |
| `weekdays` | 排在星期几（0 = 周日，2 = 周二…），默认周二、四、六 |
| `time` | 几点发（默认 19:00） |
| `templates` | 按栏目名的选题模板，`{n}` = 第几套 / 第几个；栏目名对不上的用 `generic` |
| `generic` | 通用模板：`{col}` 栏目名、`{eg}` 示例选题、`{n}` 序号 |

每条选题的案例阶段、拍法，苗苗整理后可以加进模板。
